# MonkeyBlaster 🚀

Clon de Geometry Wars desarrollado en Java con jMonkeyEngine 3.8.0 como proyecto final de la materia de Videojuegos.

---

## ▶️ Cómo ejecutar

**1. Clonar el repositorio:**
```bash
git clone https://github.com/RubenAmauri/MonkeyBlaster.git
```

**2. Abrir el proyecto en el jMonkeyEngine SDK y dar clic en Ejecutar.**

Al iniciar aparecerá un diálogo de configuración. Se recomienda:

| Ajuste | Valor recomendado |
|---|---|
| Fullscreen | No |
| VSync | Sí |
| Gamma correction | Sí |
| Screen Resolution | 1280x720 o 1920x1080 |
| Color depth | 16 bpp |
| Refresh Rate | N/A |
| Anti-Aliasing | Disabled |

---

## 🎮 Controles

| Acción | Control |
|---|---|
| Mover nave | Flechas / WASD |
| Disparar | Click izquierdo |
| Pausa | P |

---

## ⚠️ Notas

- Las opciones **2 Jugadores** y **Selección de nave** aparecen en el menú pero no están implementadas.
